## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Configure your environment variables using `.env.example` (where available).

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```

## Deployment

Deploy using your preferred hosting platform. Ensure all required environment variables and Supabase credentials are configured.
